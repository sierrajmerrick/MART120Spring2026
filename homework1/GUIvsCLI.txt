The difference between a command line interface and a graphical user interface lies in the way the user interacts with the device. A command line interface is solely text based, requiring only a keyboard as an input device. This interface requires some knowledge of syntax and structure for operation, and in turn can offer more speed and precision, as well as requiring less computing power and memory. A graphical user interface provides a visual representation of the same inner workings of a computer. This grants the user the ability to execute actions with both a keyboard and a mouse. While a graphical user interface offers more interaction, information, and accessibility than a command line interface, it is subjective to say which interface is the more user friendly of the two.
